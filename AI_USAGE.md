## 4. At Least Two AI Mistakes Found

### Mistake 1: Inefficient Full Database Scan in Memory
- **The Issue**: Originally, `InventoryRepository.saveCount()` called `dao.getAllOnce().find { it.barcode == normalizedBarcode }` to check if a barcode had already been submitted.
- **Why it was a problem**: Fetching all records from Room into memory on every single save operation degraded performance as the database grew and bypassed Room's SQL index optimization.

### Mistake 2: Form Lockout on Unlisted Barcodes
- **The Issue**: In the initial `lookupProduct()` implementation, when a barcode was not found in the mock catalog (`404 Not Found`), the AI set `productLoaded = false`.
- **Why it was a problem**: Because `productLoaded` was `false`, the UI hid the fields for Actual Quantity, Expiry Date, and the Save button. Users were completely blocked from entering inventory counts for any product not present in the hardcoded mock catalog.

---

## 5. How Those Mistakes Were Corrected

### Correction of Mistake 1 (In-Memory DB Scanning)
- **Fix**: Added `@Query("SELECT * FROM inventory_counts WHERE barcode = :barcode LIMIT 1") suspend fun findByBarcode(barcode: String): InventoryCountEntity?` directly to `InventoryCountDao`.
- **Implementation**: Updated `InventoryRepository.saveCount()` to call `dao.findByBarcode(normalizedBarcode)` directly. This leverages Room's `@Index(value = ["barcode"], unique = true)` constraint, making lookup $O(1)$ and avoiding unnecessary memory allocations.

### Correction of Mistake 2 (Unlisted Barcode Lockout)
- **Fix**: Modified `lookupProduct()` failure callback in `InventoryViewModel`.
- **Implementation**: When the mock API returns 404, `message.value` informs the user *"Product not found in catalog. Enter details manually."*, and `formState` sets `productLoaded = true` with fallback editable defaults (`"Unlisted Item"`, expected quantity `"0"`). In `InventoryHomeScreen`, `productName` and `expectedQuantity` were updated from read-only to editable text fields when manually entering custom items.
